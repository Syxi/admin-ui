# 统一媒体库使用说明

## 概述
统一媒体库页面整合了原有的文件管理、图片管理和视频管理功能，提供了一个统一的界面来管理所有类型的媒体文件。

## 主要功能

### 1. 左侧文件树
- 显示文件分类：全部文件、图片、视频、文档
- 支持按分类快速筛选
- 显示各类别文件数量统计
- 支持关键字过滤

### 2. 右侧内容区域
- 支持列表视图和网格视图两种展示方式
- 可通过视图切换按钮进行切换
- 列表视图：显示详细文件信息
- 网格视图：以缩略图形式展示媒体文件

### 3. 媒体类型筛选
- 支持按文件类型筛选：全部、文件、图片、视频
- 根据选择的类型调用相应的API查询数据

### 4. 统一上传功能
- 支持选择上传类型：通用文件、图片、视频
- 根据类型提供不同的文件类型限制和大小限制
- 图片：支持jpg/png等格式，最大5MB
- 视频：支持mp4/avi/mov等格式，最大500MB
- 通用文件：支持所有格式，最大500MB

### 5. 统一操作功能
- **预览**：图片可缩略图预览，视频可播放，PDF可预览
- **下载**：根据媒体类型调用相应的下载API
- **删除**：根据媒体类型调用相应的删除API
- **编辑**：图片支持名称编辑功能

## 视图模式

### 列表视图
- 显示文件名、大小、类型、上传时间等详细信息
- 适合需要查看详细信息的场景

### 网格视图
- 以缩略图形式展示媒体文件
- 适合图片等可视媒体的浏览
- 更直观的视觉展示效果

## 权限控制
页面保留了原有的权限控制指令：
- `v-access:code="['sys:media:upload']"` - 上传权限
- `v-access:code="['sys:media:delete']"` - 删除权限
- `v-access:code="['sys:media:preview']"` - 预览权限
- `v-access:code="['sys:media:download']"` - 下载权限
- `v-access:code="['sys:media:view:list']"` - 列表视图权限
- `v-access:code="['sys:media:view:grid']"` - 网格视图权限

## API 调用
- 文件管理：调用原有的文件管理API
- 图片管理：调用原有的图片管理API
- 视频管理：调用原有的视频管理API

通过统一的接口适配，保持了与后端服务的兼容性。
